# Portuguese Poetry Analysis
## Project Overview
This repository explores a structured *corpus* of Portuguese poetry, integrating author demographic data, editorial metadata, text processing, and Exploratory Data Analysis (EDA).

## Core Analytical Dimensions
1. **Gender Representation:** Analysis of publication distribution and recognition in literary awards over time.
2. **Thematic Distribution:** Mapping of recurring themes, their relative weight, and evolution across Portuguese literature.
3. **Geographical Analysis:** Municipality-level mapping of regional publication impact and cultural reach across Portugal.
